# MindGuard - Quick Start Guide (5 Minutes)

## 🚀 Install in 3 Steps

### 1. Open Extensions Page
```
Type this in Chrome: chrome://extensions/
```

### 2. Enable Developer Mode
- Toggle **Developer mode** (top right)

### 3. Load Extension
- Click **Load unpacked**
- Select the `/extension/` folder
- Done! ✅

## 🎯 First Run (2 Minutes)

### 1. Click MindGuard Icon
- Find it in your toolbar (or extensions menu)

### 2. Demo Login
- Click **Demo Login** button
- Email: demo@mindguard.com
- Password: demo123

### 3. You're In!
- You'll see the dashboard
- No further setup needed

## ⚡ Quick Demo (3 Minutes)

### See It Working

1. **Add a test rule:**
   - Click ⚙️ Settings
   - Go to Rules tab
   - Type `example.com`
   - Click "Add Rule"

2. **Test blocking:**
   - Visit `https://example.com`
   - See the MindGuard blocking page!
   - Try completing a challenge

3. **Check your stats:**
   - Go back to popup
   - See your stats updated
   - Check Analytics for charts

## 🆘 Quick Troubleshooting

**Icon not showing?**
- Click puzzle icon in toolbar
- Pin MindGuard to your toolbar

**Extension not blocking?**
- Hard refresh page: `Ctrl+Shift+R`
- Check the rule was added
- Make sure blocking is enabled

**Settings not saving?**
- Try hard refresh
- Restart Chrome
- Check if in Incognito mode

**Need help?**
- See [README.md](README.md)
