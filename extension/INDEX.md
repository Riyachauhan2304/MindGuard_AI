### Dashboard Features
- Focus Score tracking
- Blocked sites counter
- Completed challenges counter
- Time saved calculator
- Activity log
- Real-time status

### Blocking Features
- Add custom blocking rules
- Quick-add popular sites (12 included)
- Block/Allow actions
- Temporary unlock via challenges
- Overlay blocking page
- Domain matching

### Challenge Types
- Breathing exercises
- Quizzes
- Typing tests
- Riddles

- Focus hours configuration
- Strict mode (24/7 blocking)
- Weekend mode
- Notifications toggle
- Theme preferences
- Language selection

- Overall stats display
- Most blocked sites ranking
- Productivity insights
- Daily tracking
- Success metrics

### Data Features
- Local-only storage
- Chrome storage API
- Automatic persistence
- Manual reset option
- No cloud sync
